# ir-coordinator · 应急响应协同智能体

安全事件应急响应四位一体协同 Skill。AI 以「应急技术专家」身份，主动推动销售 / 售前 / 安服 / 售后四个角色按阶段协同处置，跨会话通过案件编号保持状态连续性。

---

## 是什么

不是被动记录工具，而是**主动推动者**。接到案件后，主动告诉每个角色：
- 当前阶段该做什么、下一步该做什么
- 谁在等你、你在等谁（跨角色协同）
- 当前阶段的关键纪律（如"不下结论性语言"）
- 按事件类型给出针对性加固方案与话术

覆盖四类事件：**银狐 / 勒索 / 入侵 / 通报**。

---

## 快速开始

对话里说触发词即可加载：`应急响应`、`应急协同`、`启动应急`、`四位一体`。

1. 选「新建案件」或「加入已有案件」
2. 新建时录入：客户名称、事件类型、客户分类（T2000 有/无产品、非 T2000、渠道）
3. 选角色：`1 销售` / `2 售前` / `3 安服` / `4 售后` / `5 指挥者`
4. AI 主动推送 5 段：⚡最该做的事 / 📋任务清单 / 🔗协同提醒 / ⚠️纪律 / 📎参考

跨会话续接：直接说「应急协同，IR-XXXX-XXXX，我是安服」。

## 五阶段流程

| 阶段 | 名称 | 一句话 |
|---|---|---|
| 0 | 接警响应 | 3 分钟定性，组建小组 |
| 1 | 赶赴现场 | 只进不出的貔貅，不下结论 |
| 2 | 现场处置 | 取证溯源 + 部署查杀 |
| 3 | 溯源汇报 | 成为向 CIO 汇报的团队 |
| 4 | 加固转化 | 3 个月内必须有 PPL |

**事件类型 → 加固方案速查**

| 事件 | 加固方案 |
|---|---|
| 银狐 | TrustOne(EDR) + AE + TDA + AI XDR 联动 |
| 勒索 | DS + 虚拟补丁 + 微隔离 + TDA 回连 + AI XDR |
| 入侵 | DS + AE + AI XDR（网络侧 + 主机侧） |
| 通报 | 虚拟补丁(VP) + AE |

**支撑方式规则**

| 客户分类 | 支撑方式 |
|---|---|
| T2000 + 有产品 | 全力现场应急 |
| T2000 + 无产品 | 支持一次现场；3 个月无 PPL 或 <50 万 → 不再现场 |
| 非 T2000 | 仅远程，特殊情况需省办主任审批 |
| 渠道转介 | 远程支持 |

## 关键纪律（AI 强制执行提醒）

1. 初始阶段**不下结论性语言**；话术"到了现场全面分析"
2. **做只进不出的貔貅**：信息向内索取，统一接口人对外汇报
3. 阶段性结论先内部讨论，再统一对外
4. **3 个月 PPL 窗口**：应急是商机入口，不是免费服务
